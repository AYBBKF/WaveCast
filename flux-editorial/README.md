# Plan éditorial Flux Intelligent : sauvegarde de travail

- `exec/suivi-execution.md` : tableau de suivi des contenus et des IDs WordPress et Surfer.
- `exec/SPEC.md`, `exec/BRIEFS.md` : cahier des charges et fiches.
- `exec/html/` : HTML final de chaque contenu.
- `exec/img/` : images générées. `<slug>.webp` est la version optimisée, `-src` l'original.
- `exec/results/` : un compte rendu JSON par contenu.
- `exec/backup/` : versions originales des contenus avant enrichissement.
- `exec/draft-*.html` : brouillons d'origine.
- `secteurs/` : cartographie des secteurs et inventaire.
